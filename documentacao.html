Documentação do Sistema - Glamourize

Esta documentação reúne todas as plataformas integradas no projeto, as chaves e tokens de configuração (variáveis de ambiente) e uma explicação detalhada de como funciona o fluxo completo de compra, pagamento e frete da loja.

1. Plataformas Utilizadas e Links Úteis

Plataforma Função Link de Acesso
Vercel Hospedagem do site e execução das rotas de backend (APIs). vercel.com
Sanity CMS Banco de dados (produtos, estoque, tamanhos e pedidos realizados). sanity.io/manage
Mercado Pago Processamento de pagamentos (Cartão de Crédito, Pix e Boleto). mercadopago.com.br
Melhor Envio Cotação de frete, geração automática de etiquetas de postagem e rastreio. melhorenvio.com.br
Resend Disparo de e-mails de confirmação e recibo para os clientes. resend.com

2. Tabela de Chaves e Tokens (Variáveis de Ambiente na Vercel)

Essas chaves devem ser cadastradas nas configurações do seu projeto na Vercel (Settings > Environment Variables) para que as conexões funcionem com segurança:

Nome da Variável na Vercel Origem do Token / Painel Descrição / Função
SANITY_WRITE_TOKEN Painel do Sanity (API > Tokens) Permissão para o site salvar novos pedidos e descontar estoque no banco de dados.
VITE_MERCADOPAGO_PUBLIC_KEY Painel do Mercado Pago (Credenciais) Chave pública do Mercado Pago, usada para carregar o formulário de pagamento no site.
MERCADOPAGO_ACCESS_TOKEN Painel do Mercado Pago (Credenciais) Token privado usado no backend para cobrar cartões, gerar QR Codes Pix e emitir boletos.
MELHOR_ENVIO_TOKEN Painel do Melhor Envio (Tokens de Acesso) Token privado usado para calcular o frete e enviar a etiqueta direto para o seu carrinho do Melhor Envio.
MELHOR_ENVIO_POSTAL_CODE Seu CEP de Origem O CEP do seu endereço de coleta de onde as roupas serão enviadas.
MELHOR_ENVIO_SANDBOX Configuração do Ambiente Define se o frete está em ambiente de testes (true) ou de vendas reais (false).
RESEND_API_KEY Painel do Resend (API Keys) Chave que autoriza o site a disparar e-mails utilizando sua conta do Resend.
EMAIL_FROM Personalizado O e-mail de remetente que o cliente verá (ex: Glamourize <contato@glamourize.com.br>).

3. Como Funciona o Sistema (O Fluxo do Pedido)

O sistema foi desenhado de forma 100% autônoma para processar as vendas automaticamente:

  • 1. Cálculo de Frete: O cliente digita o CEP no carrinho. O site envia os dados para a rota /api/shipping/calculate. O peso é calculado automaticamente a 500g por peça (envelope de segurança). A rota formata a lista para exibir opções amigáveis (Correios PAC, Correios SEDEX, Jadlog, Loggi).
  • 2. Fechamento do Pedido: O site valida todas as entradas. Se o usuário preencher o formulário mas não tiver selecionado uma forma de envio, o sistema impede o avanço e exibe um erro em vermelho.
  • 3. Processamento de Pagamento: Ao clicar em pagar, o Mercado Pago gera a transação e vincula o ID do pedido (ex: EV-123456) ao campo external_reference.
  • 4. Aprovação & Webhook do Mercado Pago: O cliente realiza o pagamento. O Mercado Pago faz um disparo automático para a nossa rota /api/payment/webhook. O site recebe a notificação e:
    • Muda o status do pedido no Sanity para "Pago" (paid) e reduz o estoque do produto.
    • Gera a etiqueta de envio com todos os dados do cliente e a **insere direto no carrinho do seu Melhor Envio** para você apenas imprimir e colar.
    • Dispara um e-mail com layout premium preto e ouro para o comprador via Resend.
  • 5. Atualização em tempo real (Pix): Se o cliente pagou por Pix, a tela dele do site detecta o pagamento de forma automática em menos de 4 segundos e o redireciona direto para a página de rastreamento com todos os dados preenchidos.
  • 6. Despacho & Webhook do Melhor Envio: Quando você postar o pacote no balcão da transportadora (ou quando o pacote for entregue na casa do cliente), o Melhor Envio dispara um aviso automático para /api/shipping/webhook. O site recebe o sinal, busca o pedido correspondente e altera o status para "Enviado" (shipped) ou "Entregue" (delivered) automaticamente.
